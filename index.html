How It Works

Three simple steps to detect fraudulent transactions

01
Enter Transaction Details

Fill in the transaction form with details like amount, type, and balance information from both sender and receiver.

02
ML Model Analyzes Data

Our Random Forest model (trained on 6M+ real records) processes the inputs and calculates fraud probability instantly.

03
Get Instant Results

See whether the transaction is fraudulent or safe, along with the confidence percentage and risk breakdown.

Features

What's Inside This Project

Built as a final-year ML project with real dataset and real results

Random Forest

Primary classifier trained on Kaggle payment dataset with high precision.

Logistic Regression

Comparison model used for benchmarking Random Forest performance.

SQLite Database

All transaction checks are stored locally for dashboard statistics.

Visual Dashboard

Charts and stats showing fraud vs. safe transaction history.

Responsive Design

Works on mobile, tablet, and desktop screens with Bootstrap 5.

Confidence Score

Each prediction shows probability percentage for transparency.

Transaction History

Past checks are listed in a clean table on the dashboard page.

Flask Backend

Lightweight Python Flask server handles API calls and DB operations.

Machine Learning

Model Performance

Trained on the PaySim dataset from Kaggle — a synthetic dataset simulating real mobile money transactions with labeled fraud cases.

Random Forest Accuracy 99.2%
Logistic Regression Accuracy 91.4%
Precision Score 98.7%
Recall Score 97.1%
Dataset Information
Source Kaggle - PaySim Synthetic Dataset
Records 6,354,407 transactions
Features 11 columns (6 used for prediction)
Fraud Cases 8,213 (≈ 0.13% of dataset)
Train/Test Split 80% Training / 20% Testing
Preprocessing Label encoding, feature scaling
