Project — Online Payment Fraud Detection System

Project Abstract

Online payment fraud has become one of the most pressing challenges in digital financial systems. This project presents a machine learning-based web application to detect fraudulent transactions in real-time. Using the PaySim synthetic dataset from Kaggle — which contains over 6 million simulated mobile money transactions — we trained a Random Forest classifier achieving 99.2% accuracy. A Logistic Regression model was also built for comparison, scoring 91.4%. The system is deployed as a Flask web application where users can input transaction details and receive instant fraud predictions along with confidence scores. All predictions are stored in an SQLite database and visualized on an admin dashboard.

Project Objectives
  • Build a fraud detection model using Random Forest on real-world inspired data
  • Compare performance with Logistic Regression baseline model
  • Create a user-friendly web interface for transaction checking
  • Store and display prediction history with an admin dashboard
  • Visualize model performance metrics (confusion matrix, accuracy)
  • Make the system accessible on both desktop and mobile devices

Conclusion

This project demonstrates that machine learning — specifically Random Forest — can effectively detect online payment fraud with very high accuracy. The web-based interface makes the model accessible to non-technical users. Key findings show that transaction amount and balance change patterns are the strongest fraud predictors. The system successfully bridges the gap between ML research and practical deployment, making it a strong foundation for a production-grade fraud detection system.
